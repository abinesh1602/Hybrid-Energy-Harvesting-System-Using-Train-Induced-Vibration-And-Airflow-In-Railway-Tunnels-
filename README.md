# 🚆 Smart Railway Track Safety System using Arduino

A smart embedded system designed to improve railway safety by detecting:

- 🚂 Approaching trains using a Piezo sensor
- 🐄 Animals roaming near railway tracks using an Ultrasonic sensor

The system alerts nearby people using:
- 🔊 Buzzer
- 💡 LED indicators
- 📺 OLED Display

---

# 📌 Features

✅ Train detection using vibration sensing  
✅ Animal detection using ultrasonic distance measurement  
✅ OLED live status display  
✅ Audio and visual warning system  
✅ Low-cost and easy-to-build prototype  
✅ Suitable for railway safety applications

# ⚙️ Working Principle

## 🚂 Train Detection
The Piezo sensor detects vibrations generated by an approaching train.

When vibration exceeds the threshold:
- OLED displays **TRAIN COMING**
- Buzzer turns ON
- LED glows continuously

---

## 🐄 Animal Detection
The Ultrasonic sensor continuously measures distance.

If an object/animal is detected within 50 cm:
- OLED displays warning message
- LED blinks
- Buzzer alerts intermittently

---

## ✅ Safe Condition
If no train or animal is detected:
- OLED displays **SAFE**
- Buzzer and LED remain OFF
