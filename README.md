# Hybrid-Energy-Harvesting-System-Using-Train-Induced-Vibration-And-Airflow-In-Railway-Tunnels-
Hybrid Energy Harvesting System Using Train-Induced Vibration and Airflow in Railway Tunnels is an innovative railway infrastructure solution that converts wasted mechanical vibration and tunnel airflow generated by moving trains into electrical energy using piezoelectric sensors and wind turbines for self-powered tunnel lighting and safety systems
